# Stopwatch

This application provides a digital stopwatch with lap time recording capabilities.

## Features

- Precise millisecond timing display
- Record individual lap times
- Scrollable history of recorded laps
- Responsive start stop and reset controls

## How it works

The application uses the JavaScript setInterval function and Date timestamps to track elapsed time. It dynamically calculates minutes seconds and milliseconds and updates the DOM elements accordingly.

## Run

Open `index.html` in a browser. No install or build step.

## Files

- `index.html`: Main markup structure for the app
- `style.css`: Complete design and layout styling
- `script.js`: Stopwatch logic and interaction handling
